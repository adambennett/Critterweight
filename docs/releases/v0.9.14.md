# Critterweight 0.9.14

This preview softens the menu focus sound after the v0.9.13 audio refresh. Menu navigation now uses three brief Kenney Interface Sounds ticks at -14 dB instead of the louder scroll effects. Selection, confirm and cancel sounds are unchanged.

An audio regression test checks the exact clips, gain, stream loading and clip duration. The source and license records remain in [the replacement audio inventory](../audio/replacement-audio-inventory.txt).
