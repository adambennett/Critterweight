# Critterweight v0.9.15 preview 2

Planned local playtest build, not a published release. Work resumed at the owner's request; the final full regression suite and refreshed executable are pending. Version remains 0.9.15; v0.9.14 is still the public release. The game has not been opened graphically.

## Changes to try

- Arena editor: View/Share switches between exclusive map controls and all surrounding menu controls. The editor popup navigates with the D-pad; toolbar, Grid snap and Team are reachable. The footer describes the active mode. Hiding a sidebar keeps menu mode active.
- New arena names gain a numeric suffix when that name already exists. Saving over an existing arena requires confirmation.
- Compendium custom arenas have pencil and trash actions with confirmation. Deletion keeps a recoverable copy in the arenas/.removed folder.
- The New rules chooser no longer has a redundant Cancel tile; Esc/B still cancels.
- Main menu Settings has a fourth entry, Patch Notes, containing all 17 published release entries through v0.9.14, available offline.
- Campaign map: scrollable/pannable vertical chart, compact newly drawn route icons, curved connections and pulsing available stops. Mouse drag/wheel and right-stick scrolling work; controller focus reveals the selected stop. Reduce-motion is respected.
- All 29 campaign events have unique generated illustrations, with the scene focus on the left and choices on the right. Outcomes retain their illustration. Campaign map, events, shops, rests and reward screens show current HP, Scrip, Hype and the carried build in a top strip.
- The campaign act-introduction popup is removed. Campaign confirmations block underlying input. The summary title no longer relies on being the first layout child.
- Abandoning a Bookie's Table run uses the current run controller even after a loss and a newly dealt card. Starting another card clears stale pause/decision state.
- Fighter health cards all occupy the top of the fight HUD. Subtitles have a separate lower band above the controls, including while watching the Bookie's Table.
- Ability cooldown seconds and a draining overlay appear on the actual input glyphs; the old A1/A2 ready text beside HP is removed. A spare charge remains visibly ready while a spent charge recharges. Essential ability prompts remain visible when the optional general control hints are hidden.
- Controller free-camera Invert Y is available in input settings and defaults off.
- Audio settings now open a Jukebox: separate main-menu, fight, boss and Cannery playlists; default soundtrack, selection-order playback, shuffle without an immediate repeat, or repeat-first-track. An empty custom playlist is silent. Settings persist. Both Cannery radio channels use the hub playlist.
- The crate-toss line sits slightly closer to the water. During the game it turns green/red with a READY/STEP BACK label using the same legality rule as the actual throw.
- Character selection's right stick scrolls the information panel. Character selection and Compendium reuse segmented fighter stats and detailed ability descriptions with live input glyphs.
- Main-menu backgrounds stop crowd and ambience completely. Combat crowd murmur/cheers again use the original generated recordings from before v0.9.13. The approved music and quiet single menu tick remain.
- Match/spectate setup groups compact fighter cards in team columns while preserving each fighter slot and controller focus. Vertical navigation reaches both columns and text remains readable at 1280×800.

The first v0.9.15 preview's saved-monitor persistence and single soft fixed-pitch menu tick remain included.

- Offline spoken dialogue: Devon leads fight commentary, Kendall adds selected comic calls and Cannery roles, and Coach Buck handles coaching/tutorials. Current authored dialogue is covered with recorded name/number fallbacks, including the owner-selected 17 custom player names and worm/werm spelling aliases. No API or connection is needed while playing.
