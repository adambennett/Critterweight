# Cage Rules guest import

The owner requested Jeremy's fighter as the seventh Critterweight fighter. This is the reproducible build adapter for Varga. It extracts the original procedural mesh, rig, poses and strike definitions; it does not run a second game engine at runtime.

## Rebuild

From the repository root, run `node tools/cage_rules/import.js`, then Godot's headless asset import. This rewrites only `game/content/core/creatures/f_varga.json` and `game/assets/models/creatures/f_varga.glb`.

`source/` contains byte-identical copies of `MMAsim/js/{sim,physics,render}.js` and `MMAsim/lib/three.min.js` from the owner's Cage Rules project. `source-manifest.json` records the original paths and SHA-256 hashes. The source project is not edited. Three.js is MIT licensed; its notice is in `source/LICENSE-three.txt`. Rapier and PeerJS are not imported. The build uses only Node's built-in modules and this retained Three.js bundle.

## Adaptations

- Original 11-segment fighter, smooth skin, face, shorts and gloves become a glTF skin bound to Critterweight's physics segments. Foot mesh weights merge into the source shin segments.
- Source strike timings, stamina costs and keyed rotations are retained. Body scale is 1.06. Damage/lunges/active-window adjustments are explicit in the adapter for this game's balance and timestep.
- Arm FK targets become IK chains for opponent-height retargeting. Kick keys retain source joints with additional arm clearance. Pelvis yaw/tilt converts to the target rotation convention. Mirrored variants supply southpaw.
- Original source poses supply stance, guard, low shell and raised-shin check. Walking uses the target engine's gait.
- New abilities, JUICE, elemental buildup, native grapple/throw rules, UI prompts and controller inputs integrate with Critterweight. Ground positions/submissions are outside this port.

`knell-build.json` records the separate original Knell model build measurements; Knell is generated by the existing forge, not Cage Rules.

The original source files are build-only and are not exported in the game PCK. The original fighter's derived model, moves and poses are exported under the owner's requested reuse authorization. This does not assign a new licence to Jeremy's source code.
